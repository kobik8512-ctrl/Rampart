How to play

Online

  • Create room — you are host (Amber). Share the 6-letter code or invite link.
  • Join room — enter the code. You play as Slate.
  • Only the player whose turn it is can move. The board syncs live.
  • If someone leaves, the room closes.

Goal

Highest score after 40 turns, or capture all enemy pieces.

  • +2 per piece alive
  • +3 if that piece is in the enemy half
  • +2 for holding the center
  • +1 per wall you own

Actions (one per turn)

  • Move — one orthogonal step to empty square
  • Push — shove adjacent enemy; if blocked behind, capture them
  • Wall — place a wall on adjacent empty square (max 5)

Local

Hotseat on one device — pass the phone each turn.
